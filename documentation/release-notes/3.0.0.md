# 3.0.0

Breaking target-framework cut. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0` (one `<Version>` in `source/Directory.Build.props`). The public symbol surface is the `2.0.0` surface. This note records the framework change. It is not a NuGet publish.

## Breaking changes

- Both packages target `net11.0` only. `net10.0` is gone. A project that still targets `net10.0` cannot reference `3.0.0`.
- The repo SDK pin is `11.0.100-rc.3.26522.148` (`rollForward: latestFeature`, `allowPrerelease: true`). .NET 11 is RC3, go-live licensed, and not GA. GA remains scheduled for 2026-11-10.
- `Microsoft.CodeAnalysis.NetAnalyzers` is `11.0.100-rc.3.26522.148`, the analyzer build that matches that SDK. CodeStyle stays `5.9.0`, BannedApiAnalyzers and PublicApiAnalyzers stay `5.6.0`, and Roslynator stays `5.0.0`. Those packages have no newer stable build that matches this SDK.

## Unchanged

- CliWrap `3.10.5` remains the process library. The .NET 11 `Process` APIs are not adopted in this cut.
- `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` githook pins in `Directory.Packages.props` stay at the published `2.0.0` packages until `3.0.0` is on the feed.
