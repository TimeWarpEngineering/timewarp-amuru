# 3.0.0-beta.2

Second prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.2` (one `<Version>` in `source/Directory.Build.props`). This note records the JSON-RPC client and the timeout grace-period change. It is not a NuGet publish.

## What is new

- Amuru-native JSON-RPC client (task 083). `ShellBuilder.AsJsonRpcClient()` returns a `JsonRpcClientBuilder`. `StartAsync` returns a `JsonRpcClient`.
- `WithJsonSerializerContext` takes a source-generated serializer context. `WithJsonSerializerOptions` is the alternative. `WithStandardErrorObserver` receives the child's standard error.
- The dev CLI reports telemetry through `UseTelemetry` (tasks 139 and 140).

## New dependency

- `TimeWarp.Ramani` `1.0.0-beta.23` (task 138) runs the internal session machine. It comes from nuget.org and depends only on `TimeWarp.Builder` `1.0.0`.

## Behavior change

- A child that exits during the timeout grace period reports its own exit code and `TimedOut` false (task 141). A stream reader that is still behind receives the lines that child wrote; that exit is not rewritten to 124. When the grace period elapses, the result is still exit 124 and `TimedOut` true. On Unix an unhandled SIGINT is exit 130 and is not a timeout.

## Unchanged

- CliWrap stays the process library for ordinary commands (task 119). The JSON-RPC child uses the .NET 11 handle APIs.
- `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` githook pins in `Directory.Packages.props` stay at the published `2.0.0` packages until `3.0.0-beta.2` is on the feed.
