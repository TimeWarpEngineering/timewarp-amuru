# 3.0.0-beta.7

Seventh prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.7` (one `<Version>` in `source/Directory.Build.props`). This note records the typed `dotnet msbuild` and `dotnet nuget verify` builders (task 151). It is not a NuGet publish.

## Added

- `DotNet.MsBuild()` / `DotNet.MsBuild(project)` builds `dotnet msbuild`. Targets (`WithTarget`, `-t:`), properties (`WithProperty`, `-p:`), and the `-getProperty:` / `-getItem:` / `-getTargetResult:` queries are repeatable and emitted in call order. `WithVerbosity`, `WithRestore`, `WithNoLogo`, and `WithBinaryLog()` / `WithBinaryLog(path)` cover the rest. It sets the same `build.command` (`msbuild`) and `build.configuration` span tags as `DotNet.Build()`, and runs with trace context propagation like every other command.
- `DotNet.NuGet().Verify(packagePath)` builds `dotnet nuget verify` with `WithAll`, repeatable `WithCertificateFingerprint`, `WithVerbosity`, and `WithConfigFile`.

A test now pins that `DotNet.NuGet().Push()` puts neither the api key nor the symbol api key into any span tag.

## Public API

`TimeWarp.Amuru.Tools` `PublicAPI.Unshipped.txt` lists `DotNetMsBuildBuilder`, `DotNetNuGetVerifyBuilder`, `DotNet.MsBuild`, and `DotNetNuGetBuilder.Verify`. `TimeWarp.Amuru` has no public API change.

See [DotNet fluent API](../../source/timewarp-amuru-tools/dot-net-commands/dot-net.md).
