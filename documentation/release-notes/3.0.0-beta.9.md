# 3.0.0-beta.9

Ninth prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.9` (one `<Version>` in `source/Directory.Build.props`). This note records the typed `gh` builders (task 152). It is not a NuGet publish.

## Added

- `Gh` builders in `TimeWarp.Amuru.Tools` for the GitHub CLI: `Gh.Run().List()` / `.Download()`, `Gh.Api(endpoint)`, `Gh.Auth().Token()` / `.Status()`, `Gh.Issue().List()` / `.Create()`, `Gh.Pr().View()` / `.Checks()` / `.Create()` / `.Merge()`, and `Gh.Release().List()` / `.Create(tag)`. `WithRepo`, `WithJson`, `WithJq`, and `WithLimit` are on the builders whose command takes them; `WithArgument` appends anything else.
- Each execution opens a span `gh <verb> <sub-verb>` on the `ActivitySource` `Gh.ActivitySourceName` (`TimeWarp.Amuru.Gh`) with `gh.command`, `gh.repo`, `gh.api.endpoint` (path only), `gh.exit_code`, and `gh.elapsed_ms`. No argument, field value, body, token, or stdout reaches the span. `TRACEPARENT` (task 149) names that span.
- Typed results: `ListRunsAsync()` (`GhWorkflowRun` list), `ViewPullRequestAsync()` (`GhPullRequest`), and `GetStatusAsync()` (`GhAuthStatus`: signed-in flag, host, login).

## Changed

- AMURU0001 now also reports `Shell.Builder("gh")` and `Shell.Run("gh", ...)` for the commands above, naming the `Gh` builder. Other `gh` commands are not reported.
- The dev CLI's release workflow uses the `Gh` builders for its `gh run list`, `gh api`, and `gh run download` calls.

## Public API

`TimeWarp.Amuru.Tools` `PublicAPI.Unshipped.txt` lists `Gh`, the `Gh*Command` groups, the `Gh*Builder` types and their bases, and the typed result types. `TimeWarp.Amuru` has no public API change.

See [Gh fluent API](../../source/timewarp-amuru-tools/gh-commands/gh.md).
