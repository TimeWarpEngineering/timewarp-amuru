# 3.0.0-beta.6

Sixth prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.6` (one `<Version>` in `source/Directory.Build.props`). This note records automatic trace context propagation to child processes (task 149). It is not a NuGet publish.

## Changed

- Every child process Amuru starts joins the caller's trace. When `Activity.Current` is set at the moment the command starts, Amuru sets `TRACEPARENT` (`00-{traceId}-{spanId}-{01|00}`, flags from `ActivityTraceFlags.Recorded`) on the child, and `TRACESTATE` when `Activity.TraceStateString` is non-empty. That covers the CliWrap execution modes, every `Pipe` stage, `TtyPassthroughAsync`, and `AsJsonRpcClient`.
- The value is resolved at start time, so a `CommandResult` built before a span opens still propagates the span current when it runs.
- With no current activity the child environment is untouched, so an inherited `TRACEPARENT` still applies.
- A value set through `WithEnvironmentVariable(s)` wins. A `null` value removes the variable, which opts the child out.

Consumers that set `TRACEPARENT` by hand (Jaribu's dev CLI `TraceParentPropagation`, ganda's `dotnet-invocation-trace.cs`) can drop that code once they are on this version.
