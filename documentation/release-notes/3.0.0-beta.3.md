# 3.0.0-beta.3

Third prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.3` (one `<Version>` in `source/Directory.Build.props`). This note records a dependency refresh and the githook self-pin move. It is not a NuGet publish.

No behavior change. The public symbol surface stays the `3.0.0-beta.2` surface. Both `PublicAPI.Unshipped.txt` files stay header-only.

## Dependency updates

`ganda nuget outdated` on this branch reported three packages. The versions taken:

| Package | Was | Now | Where used |
|---|---|---|---|
| TimeWarp.Ramani | 1.0.0-beta.23 | 1.0.0-beta.24 | core package (internal JSON-RPC session machine) |
| TimeWarp.SourceGenerators | 1.0.0-beta.11 | 1.0.0-beta.12 | build |
| Microsoft.Extensions.Hosting | 10.0.1 | 10.0.14 | MCP stdio validation server under tests only |

`TimeWarp.Ramani` `1.0.0-beta.24` adds the Blazor demo, the interactions package, and the class-diagram page. The core package and its generator are unchanged from `1.0.0-beta.23`, so the session machine and the command-completion oracle are unchanged.

`TimeWarp.SourceGenerators` `1.0.0-beta.12` ships analyzers only. It removes the retired interface-delegation generator and diagnostics TW0002, TW0003, TW0004, TW0005, and TW0006. Live diagnostics remain TW0001 and TW0007, which this repo already uses.

`Microsoft.Extensions.Hosting` has no stable 11.0 on nuget.org. The newest listed build is `11.0.0-rc.3.26522.148`, and the newest stable build is `10.0.14`. The pin is `10.0.14`. It stays test-only and does not enter the shipped graph.

Analyzer pins that match the SDK stay. `ganda nuget outdated` reported them up to date: NetAnalyzers `11.0.100-rc.3.26522.148`, CodeStyle `5.9.0`, BannedApiAnalyzers `5.6.0`, PublicApiAnalyzers `5.6.0`, and Roslynator `5.0.1`.

## Githook self pins

`TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` in `Directory.Packages.props` move from the published `2.0.0` packages to `3.0.0-beta.2`. `2.0.0` targeted `net10.0`. `3.0.0-beta.2` targets `net11.0` only. The `.githooks` runfiles consume those pins through central package management. They restore and run on the SDK this repo pins in `global.json` (`11.0.100-rc.3.26522.148`, `rollForward: latestFeature`). A machine whose SDK cannot target `net11.0` cannot run the hooks against this pin.

`ganda nuget outdated` still compares `TimeWarp.Amuru` on the stable channel, so it does not propose this move.

## Unchanged

- CliWrap stays the process library for ordinary commands. The JSON-RPC child uses the .NET 11 handle APIs.
- A child that exits during the timeout grace period still reports its own exit code and `TimedOut` false. A grace-period kill is still exit 124.
- No public members were added or removed.
