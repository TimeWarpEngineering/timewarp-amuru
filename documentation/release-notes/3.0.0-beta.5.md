# 3.0.0-beta.5

Fifth prerelease of 3.0. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` ship together at `3.0.0-beta.5` (one `<Version>` in `source/Directory.Build.props`). This note records two additions to `ShellBuilder` (task 145). It is not a NuGet publish.

The two additions let a caller run an agent in process instead of through `bash -c '… | tee -- out'`.

## Added

- `ShellBuilder.WithStandardOutputTee(string filePath)` copies the child's standard output to a file, byte for byte, as the bytes arrive. Every execution mode except `TtyPassthroughAsync` keeps its normal result: captured stdout, stderr, and exit code are unchanged. The tee does not split lines, so an unterminated last line is in the file while the child still runs. Each chunk is flushed at once, and the file is shared for read, write, and delete, so another reader can tail it during the run. A cancelled or timed-out run keeps the bytes written so far. Standard error is not written to the file. For a `Pipe` composition the tee records the last stage's stdout.
- `ShellBuilder.WithStandardInputFile(string filePath)` uses a file as the child's standard input. The bytes are streamed with no text decoding. It replaces an earlier `WithStandardInput(string)`, and a later text call replaces it. A missing file throws `FileNotFoundException` when the command runs.

Both paths are made absolute against the current directory when the builder method is called.

`TtyPassthroughAsync` and `AsJsonRpcClient` refuse both options with `InvalidOperationException`.

Under `CommandMock`, a matched call records the stdin file's text, which `CommandMock.GetConfiguredStandardInput` returns. The tee file is created when the setup matches and receives the setup's stdout text after its delay.

## Public API

`PublicAPI.Shipped.txt` for `TimeWarp.Amuru` gains the two `ShellBuilder` methods. Both `PublicAPI.Unshipped.txt` files are header-only. `TimeWarp.Amuru.Tools` has no API change.

See [Command execution](../developer/reference/command-execution.md#standard-input-file-and-stdout-tee).
